Token Launch Radar ranks the 198 pre-token protocols in DefiLlama's sealed 2026-11-14 snapshot by implied token value — a comps-anchored model (category median FDV/TVL, sublinear TVL scale, 7-day growth, tokenless maturity) — and gives each one a seven-step farm plan in a sortable, filterable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
