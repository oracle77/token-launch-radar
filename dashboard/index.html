How the number is built

  1. Comps. The median FDV/TVL of live-token protocols in the same category, taken from this snapshot. A category with fewer than 3 live comps falls back to the snapshot-wide median. No protocol name is ever special-cased.
  2. Scale. (TVL / $1M)^-0.1, clamped to [0.40, 0.95]. Value grows sublinearly with TVL: a $10B protocol is not worth 100× a $100M one.
  3. Growth. 1 + 0.45 × tanh(clamped 7-day TVL change / 60). A +400% week is worth at most +45%; a −80% week costs at most −39%. Unknown change scores 1.00.
  4. Maturity. 0.55 + 0.45 × (1 − exp(−age / 730 days)). A protocol that held value tokenless for years has proven it can do so without a token. Unknown age scores 0.75.

What this is not

Implied value is this entry's own claim, never make.fun's. “Records no token” means the snapshot's record carries no token — a protocol on the list may still have one its record misses. Nothing here predicts whether or when a token launches, and no farm step promises one.
